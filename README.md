# To-Do List

# About the Project
To-Do List is an iOS application built using Swift and UIKit. It allows users to create, manage, and track their daily tasks efficiently.

# Features
- Add, edit, and delete tasks
- Mark tasks as completed
- Save tasks using Core Data for persistence
-  Storyboard UI
- Categorize tasks (Work, Personal, Shopping, etc.)
- Dark mode support

#  Project Structure
- `ToDoList.xcodeproj` - Xcode project file
- `ToDoList/` - Source code and UI components

# Requirements
- iOS 14.0+
- Xcode 14+
- Swift 5+

# Installation
1. Clone the repository: `https://github.com/Jayalakshmi-ios/ToDoList.git`
2. Open `ToDoList.xcodeproj` in Xcode.
3. Run the app on a simulator or a real device.
